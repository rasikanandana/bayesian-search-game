Bayesian Search Game

A simple Sinhala + English game to learn Bayesian search theory

සිංහල උපදෙස්

ඔබේ යතුර නැතිවෙලා. යතුර තැන 4කින් එකක තියෙනවා. Hidden key එක probability අනුවම තෝරනවා. වැඩිම probability තියෙන තැන search කරන්න. හමු නොවුනොත් probabilities update වෙන්නේ Bayes' formula එකෙන්.

Detection probability කියන්නේ: “යතුර ඇත්තටම ඒ තැන තියෙනවා නම්, search කළාම හොයාගන්න chance එක”. 100% නෙමෙයි, මොකද හොඳට බැලුවත් සමහර විට miss වෙන්න පුළුවන්.

English Instructions

You lost a key. The key is hidden in one of four places. The hidden place is selected using the shown probabilities. Search the place with the highest probability first. If you do not find the key, the probabilities are updated using Bayes' formula.

Detection probability means: “If the key is really in the place you searched, what is the chance that your search will find it?” It is not always 100%, because even a careful search can miss the key.

Learning Note / ඉගෙනගන්න කරුණ

SS Central America නෞකාව සොයද්දීත් මේ වගේම අදහසක් භාවිත කළා. වෙනස තමයි මෙතන යතුරක්. එතන නැවක්. මෙතන ගෙදර තැන්. එතන මුහුදු කලාප. Search කළත් හමු නොවුනොත්, ඒ තොරතුර භාවිත කරලා ඊළඟට සොයන්න ඕන තැන ගණනය කරනවා.

A similar idea was used in the search for the SS Central America. Here we search for a key; there they searched for a shipwreck. Here the locations are places in a house; there the locations were ocean search areas. A failed search is still useful information, because it helps update the next best place to search.

How to publish on GitHub Pages

  1. Create a new GitHub repository, for example bayesian-search-game.
  2. Create a file named index.html.
  3. Copy this full code into index.html and commit it.
  4. Go to Settings → Pages.
  5. Under Build and deployment, choose Deploy from a branch.
  6. Select the main branch and /root folder, then save.
  7. After a short time, GitHub will give you a public website link.
